# 六連桿構型探索與運動分析平台

**版本定位**：初期驗證（單一自由度平面六連桿 / 1-DOF Planar Six-Bar Linkage）

---

## 版本核心功能

本版本以**單一自由度平面六連桿機構**作為驗證案例，主要驗證大型語言模型（LLM）是否能透過自然語言理解使用者的機構需求，並透過 **Function Call** 將需求轉換為結構化參數。

系統**不直接由 LLM 判定工程結果**，而是由**確定性的數值演算法**負責最終驗證，以建立可追溯、可驗證的 AI 工程分析流程。

> **免責聲明**  
> 本軟體僅供工程輔助選型與數值分析參考，不構成設計、製造或安全上之保證。功能推薦結果不保證枚舉全部實根。使用者應依適用之設計規範、標準與實務自行驗證後採用。本團隊不負擔任何直接或間接之法律責任。

## 商業背景與需求痛點分析

### 企業痛點（Enterprise Pain Points）

在傳統製造業、自動化設備及精密機械的研發過程中，機構概念設計往往面臨高度複雜性與資訊不足的挑戰。目前的機構研發流程，主要存在以下三大核心痛點：

1. **構型資訊分散，設計盲區難以突破**  
   機構設計相關資料與案例分散於各類文獻、專利及資料庫中，工程師往往需要查閱大量資料，才能找到合適的構型，降低概念設計效率。

2. **試誤與返工成本高昂**  
   工程師通常需完成 CAD 建模與運動模擬後，才能發現死點、干涉或運動條件不符等問題，導致設計需要反覆修改，甚至浪費數週的開發時間。

3. **關鍵經驗難以傳承，形成經驗斷層**  
   機構設計高度依賴資深工程師的經驗與直覺，但這些隱性知識難以系統化、模組化與複用，使團隊在人才交替時容易產生技術與經驗斷層。

### 使用者需求（User Personas & Requirements）

本平台主要服務三類使用者，分別從學術學習、工程研發與專案管理三個面向切入，提供不同層級的機構設計與分析支援。

| 使用者角色 | 核心需求 | 平台解決方案 |
|------------|----------|--------------|
| **學術與教學研究人員**（Academic & Educational Researchers） | 了解機構學相關知識，並建立從拓樸結構、運動原理到實際機構運動行為的完整理解。 | 完整保留機構求解與分析過程中的推導、判斷與計算紀錄，供研究人員進一步查看與分析，協助使用者理解機構理論與實際運動行為之間的關聯。 |
| **機構研發工程師**（R&D Engineer） | 根據行程、停歇或特定軌跡等設計需求，快速尋找合適的機構構型，並即時驗證尺寸參數、運動範圍及機構可行性。 | 透過自然語言 AI 構型推薦，協助使用者從設計需求快速對應適合的機構類型，並結合後續的構型辨識、數值求解與運動驗證流程，以演算法與計算結果驗證 AI 推薦結果，降低大型語言模型可能產生的幻覺問題。 |
| **研發主管／專案經理**（PM / Director） | 縮短產品研發前期的 Concept Design 週期，降低試模、打樣與反覆修改所造成的時間、開發成本與專案風險。 | 建立標準化且可追溯的機構分析流程，透過專案 JSON 參數紀錄與分享機制、量化分析報表及可追溯的計算日誌，協助團隊保留完整的設計決策依據，提升跨成員協作效率與研發管理能力。 |

## 流程比較

### 現況流程（As-Is Workflow）

傳統機構設計流程通常從提出運動需求開始，接著由工程師人工查閱手冊、文獻或既有案例，以尋找合適的機構構型。確定構型後，再憑藉工程經驗假設初始尺寸，並建立 CAD 模型進行運動模擬與測試。

然而，若在模擬過程中發現機構運動不符合需求，工程師必須重新調整尺寸參數並反覆驗證。整體流程高度依賴人工經驗與試誤，往往需要經過多次建模、模擬與修改，才能完成初步可行性驗證。

```
提出運動需求
    ↓
人工查閱手冊／文獻
    ↓
選擇適合構型
    ↓
依經驗假設尺寸
    ↓
 CAD 建模
    ↓
反覆模擬與修改
    ↓
 確認結果
```

### 改善後流程（To-Be Workflow）

改善後，使用者可直接以自然語言描述所需的運動需求，由 AI 協助推薦合適的機構構型，並透過 Function Call 自動轉入對應的機構分析流程。

系統接著進行閉迴路數值求解（Newton-Raphson Method），並依序完成迴路（Circuit）、分支（Branch）與幾何條件驗證，最後透過運動模擬確認機構是否符合設計需求。

透過「**AI 推薦 + 演算法求解 + 可驗證分析**」的流程，降低傳統流程中人工查找與反覆 CAD 試誤的時間成本，並縮短初步機構設計與驗證的作業時間。

```
   使用者自然語言
        ↓
    AI語言模型
        ↓
需求理解 / 機構候選推薦
        ↓
  Function Call
        ↓
    結構化參數
        ↓
    拓樸選定
        ↓
  Newton-Raphson
        ↓
Circuit / Branch
        ↓
Geometry Validation
        ↓
    運動結果
```

此流程優化，預期降低人工查找、參數試誤與重複模擬所需的時間。

## 團隊願景

本團隊立志打造一套以 **AI 與機構學演算法**為核心的智慧機構設計平台，目標是將傳統依賴工程師經驗、文獻查找與反覆 CAD 試誤的機構概念設計流程，轉化為**自然語言需求輸入、AI 輔助構型選擇，以及工程演算法驗證**的數位化流程。

平台的核心目標是在進入 CAD 建模之前，先完成機構構型選擇、基本尺寸規劃與運動可行性驗證，降低前期設計的試誤成本，讓工程師能以更有效率的方式完成 Concept Design。

## 本次專案導入 AI 之設計

考量開發時間與研究範圍，本次專案以平面六連桿機構作為 AI 智慧設計與運動學分析平台的驗證案例。目前系統已完成三項核心目標：

1. **建立 AI 與工程分析整合流程**  
   本平台並非單純的 AI Chatbot，而是將 AI 導入實際的機構設計流程，串接構型推薦、拓樸辨識、運動學求解與結果驗證等功能。  
   透過「AI 理解需求 → 確定性演算法執行分析驗證 → 動態視覺化呈現」的流程，建立一套可追溯、可驗證、可檢查的工程分析架構，降低僅依賴大型語言模型所可能產生的幻覺問題。

2. **導入 AI 智慧助手，降低資訊與經驗門檻**  
   將 AI 導入機構概念設計流程，使使用者能透過自然語言描述設計需求，由系統協助理解運動特徵並推薦可能的機構構型。  
   此機制可降低傳統機構設計中大量查閱資料與搜尋案例的時間成本，同時協助保存與整合工程知識，減少因資料分散與工程師經驗斷層所造成的設計效率問題。

3. **依據論文建立嚴謹的運動學解析**  
   系統依據相關機構學理論與研究文獻，建立六連桿機構的拓樸辨識、閉迴路方程式數值求解、迴路與分支分析及幾何條件驗證。  
   透過完整的分析流程與可視化結果，系統不僅提供最終答案，也保留求解與驗證過程，可作為學術研究人員、新進工程師與機構學習者理解六連桿機構理論與實際運動行為的輔助平台。

## 操作 SOP

### SOP 1：構型智慧推薦（Function Recommendation）

**適用情境**：已有運動目標（如夾持、避障、步態、快回），但尚未決定使用何種機構構型。

**操作步驟**：

1. 進入首頁點擊「**構型智慧推薦**」。
2. （可選）點擊右上角「AI 設定」，輸入 Gemini 或 OpenAI API Key；亦可直接使用系統內建之專家啟發式評分。
3. 輸入自訂運動需求（例如：「*需要末端平穩夾取零件，在行程最後具有較大夾持力*」）或直接挑選預設情境。
4. 檢視前三名推薦構型、雷達能力圖、適配原因與工程風險。
5. 點擊「**套用此構型**」，系統自動將該構型與預設參數帶入後續運動分析流程。

---

### SOP 2：機構名稱辨識（Topology Identification）

**適用情境**：已有一組六連桿連接關係，需確認其標準學術命名與拓樸分類。

**操作步驟**：

1. 進入首頁點擊「**機構名稱辨識**」。
2. 依序填入 6 根連桿（L1～L6）上的接頭名稱（如 `A, B` 或 `A, D, G`），並指定固定桿與驅動桿。
3. 點擊「**執行辨識**」，系統依圖論演算法進行四步驟判定（Watt/Stephenson → 4/5 桿側 → B/T 輸入 → Ⅰ/Ⅱ/Ⅲ 型）。
4. 檢視辨識結果與連通圖，點擊「**套用辨識結果**」載入幾何工作區。

---

### SOP 3：機構迴路分析（Circuit / Branch Kinematic Analysis）

**適用情境**：已知機構構型與尺寸，需驗證能否轉完全週、是否存在死點缺陷，並觀察連桿運動軌跡。

**操作步驟**：

1. 進入首頁點擊「**機構迴路分析**」，選擇指定構型（如 `SIIIB4`）。
2. **步驟 2 幾何尺寸**：輸入各桿長度與鉸鏈座標，即時預覽骨架。
3. **步驟 3 初始構形**：微調組裝初始角度。
4. **步驟 4 分析條件**：設定驅動角範圍（預設 \(0^\circ \sim 360^\circ\)）、步進解析度與收斂容許值。
5. **步驟 5 指定位置**：查看特定驅動角度下各接頭座標數值。
6. **步驟 6 執行分析**：啟動 Newton-Raphson 求解與 Circuit / Branch 聚類運算。
7. **步驟 7 分析結果**：檢視連續轉動狀態、死點角度、傳動角簽章，並使用 Canvas 動畫播放運動模擬與 Coupler Point 軌跡。

## 支援的九種六連桿構型

系統支援以下九型（命名規則依論文）：

- **Stephenson 系列**：SⅠT₄、SⅡT₅、SⅡB₅、SⅢB₄、SⅢB₅  
- **Watt 系列**：WⅠB₄、WⅠT₄、WⅡB₄、WⅡT₄

## 使用建議

1. **瀏覽器**：建議使用最新版 Chrome、Edge 或 Firefox。
2. **資料驗證**：輸入尺寸後請務必核對拓樸圖，避免接頭編號錯誤。
3. **分析精度**：角度步進越小、容差越嚴，計算時間越長，但結果更精確。
4. **推薦結果**：智慧推薦僅為前置選型參考，實際尺寸合成與運動驗證仍需後續分析確認。
5. **匯出資料**：分析結果可匯出 JSON，方便後續與其他 CAD / 模擬軟體整合。
